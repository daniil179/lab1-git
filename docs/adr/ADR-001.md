# ADR-001 Модульный монолит и PostgreSQL
Статус: принято для проектирования MVP.
Контекст: требуется единый журнал QR/RFID и событий перевозчика, без распределённых транзакций.
Решение: .NET 8 API; Core с портами; адаптеры Infrastructure; PostgreSQL с unique(source,event_id); клиент по MVVM. Учебный прототип использует InMemoryTrackingRepository, а не подключённый PostgreSQL.
Альтернативы: микросервисы (дороже эксплуатация), общая БД внешних систем (сильная связанность).
Последствия: простое развёртывание, единые транзакции; масштабирование пока целым API. Для реального PostgreSQL нужны миграции и Npgsql-адаптер, которых прототип не реализует.
