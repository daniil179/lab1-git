# Паспорт АИС Логистический хаб
Вариант 3. Заказчик учебный, владелец продукта — руководитель хаба.
Роли: оператор склада, диспетчер, администратор.
UC1: оператор регистрирует QR/RFID-событие; UC2: диспетчер получает историю отправления; UC3: администратор управляет устройствами и правами зон.
Границы MVP: приём и нормализация событий; отслеживание; контракты доступа. Не входят биллинг и оптимизация маршрутов.
Артефакты: архитектура C4, OpenAPI и Data Mapping, C# solution и проверки, регламент Git Flow/ADR.
Критерии: стабильный ключ source/eventId; UTC с offset; числовой вес кг; проверяемые ошибки; отсутствие секретов в Git.
