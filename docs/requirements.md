# Требования и сценарии использования

| Роль | Задачи и ограничения |
| --- | --- |
| Оператор склада | Сканирует идентификатор, регистрирует складское событие. Работает только со своим складом; не изменяет права доступа. |
| Диспетчер | Находит отправление по трек-номеру, просматривает историю и актуальный статус. Не исправляет первичные события задним числом. |
| Администратор | Ведёт устройства, склады и разрешения по зонам. Изменения прав подлежат аудиту; истории отправлений не удаляются. |

| Код | Функциональное требование |
| --- | --- |
| FR01 | Проверять QR/RFID и реквизиты события до регистрации. |
| FR02 | Преобразовывать события перевозчика в TrackingEvent. |
| FR03 | Исключать повторную запись по паре source и eventId. |
| FR04 | Выдавать историю по trackingNumber с ограничением limit от 1 до 100. |
| FR05 | Проверять разрешение на склад и зону на стороне сервера. |
| FR06 | Протоколировать решение по доступу без исходных значений пропуска. |

| Сценарий | Основной поток и результат |
| --- | --- |
| UC01 Регистрация сканирования | Инициатор: оператор. Условия: устройство зарегистрировано, отправление известно. Оператор сканирует метку; адаптер передаёт событие; сервер валидирует поля, нормализует данные и сохраняет уникальное событие. Результат: история дополнена. |
| UC02 Просмотр истории | Инициатор: диспетчер. Условие: действующее право чтения. Вводит LH-2026-000003; клиент вызывает GET истории; API возвращает события в порядке времени и актуальный статус. Результат: диспетчер видит движение отправления. |
| UC03 Настройка доступа | Инициатор: администратор. Условие: отдельное право управления. Выбирает устройство и склад, назначает разрешённые зоны, подтверждает изменение. Результат: новая политика сохранена, записано событие аудита. |

| Каталог или файл | Назначение |
| --- | --- |
| src/ | AIS.Core, AIS.Infrastructure, AIS.UI и AIS.Api — производственные модули. |
| tests/AIS.Tests/ | Исполняемые проверки маппинга, хранилища, доступа и ViewModel. |
| docs/ | Архитектура, контракты, ADR и регламенты разработки. |
| ops/hooks/ | Серверный обработчик защиты main для локального стенда. |
| assets/fixtures/ | Каталог тестовых двоичных данных из полного комплекта проекта; в этой публикации не требуется для сборки и проверок. |
| LogisticsHub.sln | Объединяет пять проектов; компиляционные файлы в Git не включаются. |
