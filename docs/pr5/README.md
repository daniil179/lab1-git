# Практическая работа № 5. Стратегия ветвления Git Flow

**МДК.02.02, вариант 3.** АИС «Логистический хаб».

| Ветка | Назначение |
| --- | --- |
| `main` | Выпуски с тегом. |
| `develop` | Интеграция задач. |
| `feature/*` | Работа по отдельной задаче. |
| `release/*` | Стабилизация выпуска и возврат исправлений в develop. |
| `hotfix/*` | Срочное исправление выпуска и перенос в develop. |

Для задачи LH-003 разобран путь от изменений сортировки истории до проверки кода и выпуска 1.0.0. Серверный hook проверен на отдельном репозитории: слияние релиза принято, прямая запись отклонена.
