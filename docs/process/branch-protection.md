# Защита main
Локальный bare-репозиторий защищён pre-receive hook: запрет удаления и force push, запрет прямого одиночного коммита, разрешён fast-forward до merge commit с сообщением Merge release/ или Merge hotfix/.
Это учебная техническая проверка, не полноценная система идентификации: имеющий файловый доступ администратор может изменить hook; сообщение коммита не доказывает code review.
Для командного сервера: отдельные учётные записи и SSH/HTTPS; Developer пишет feature, Tech Lead управляет merge; main требует PR, 1 независимое approval, успешный build-and-test, закрытые обсуждения, запрет force push и удаления, применение правил к администраторам. На GitHub это нужно применить после создания реального приватного репозитория. Размещение на GitHub не выполнялось.
