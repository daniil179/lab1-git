## Проект

Проект объединяет события перевозчика и складских терминалов и показывает историю отправлений.

- [Требования, роли и сценарии](docs/requirements.md)
- `src/` — предметная модель, адаптеры, API и модель представления.
- `tests/` — консольные проверки логики.
- `docs/` — проектные документы и контракты.

Сборка и запуск проверок с .NET 8:

```bash
dotnet build LogisticsHub.sln
dotnet run --project tests/AIS.Tests
```

Прототип хранит историю в памяти. SQL-схема и XAML представлены как проектные материалы.
